# AI Summary-Only Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the notice compose form a three-way analysis mode selector whose cheapest mode fills only the fields the form cannot collect, and make the three-line summary a visible, editable field that doubles as the source of truth on save.

**Architecture:** All changes are browser-side, in `js/admin.js`, `admin.html`, and `css/admin.css`. The `#ai-skip-verification` checkbox becomes an `#ai-mode` select read through one accessor, `currentAiMode()`. `runNoticeAnalysis` branches on that mode to pick one of two prompts and to decide whether the verification pass runs. A new `#post-ai-summary` textarea replaces the `composeAiSummary` module variable. The stored notice shape is unchanged, so the server, the SQL schema, and the public page are untouched.

**Tech Stack:** Vanilla browser JavaScript (no modules, no build step for `js/`), Node's built-in test runner, `scripts/prepare-public.mjs` for the `public/` mirror.

---

## Background an engineer needs before starting

Read `docs/superpowers/specs/2026-07-29-ai-summary-only-mode-design.md` first. Beyond it:

- **`js/` is the source; `public/` is generated.** `npm run prepare:public` deletes `public/` and recopies it. Never edit `public/` by hand. The Express server serves `public/` only, so a change is invisible locally until you rebuild.
- **`js/admin.js` is a plain script, not a module.** Functions called from HTML `onclick` must be top-level declarations.
- **Tests assert on source text.** `tests/public-build.test.js` reads `js/admin.js` as a string and regex-matches it. Renaming a function can fail a test far from your change. Run the full suite, not just one file.
- **`GEMINI_API_KEY` is absent locally**, so the analysis path cannot be exercised by hand. Tests are the only local verification.
- Run the full suite with `npm test`. It takes about 15 seconds and currently reports 170 passing.

```js
// AI 분석 범위. summary는 폼에 입력란이 없는 항목만 채우고 내가 쓴 값은 건드리지 않는다.
const AI_MODES = ['full-verified', 'full', 'summary'];

function currentAiMode() {
    const value = document.getElementById('ai-mode')?.value;
    // 선택기가 없거나 모르는 값이면 가장 정확한 모드로 떨어진다.
    return AI_MODES.includes(value) ? value : 'full-verified';
}

function onAiModeChange() {
    localStorage.setItem('eceAiMode', currentAiMode());
}

function restoreAiModeChoice() {
    const select = document.getElementById('ai-mode');
    if (!select) return;
    let stored = localStorage.getItem('eceAiMode');
    if (!AI_MODES.includes(stored)) {
        // 체크박스를 쓰던 브라우저의 설정을 한 번만 옮겨온다.
        stored = localStorage.getItem('eceAiSkipVerification') === '1' ? 'full' : 'full-verified';
        localStorage.setItem('eceAiMode', stored);
    }
    localStorage.removeItem('eceAiSkipVerification');
    select.value = stored;
}
```
