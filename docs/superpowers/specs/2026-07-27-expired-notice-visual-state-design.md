# 마감 공지 시각 상태 설계

## 목표

마감 임박 공지의 빨간 강조와 혼동하지 않으면서, 이미 마감된 공지를 목록과 상세 화면에서 즉시 구분할 수 있게 한다. 공지 내용의 가독성과 기존 클릭·필터 동작은 유지한다.

## 상태 판정

- 기존 `calcDDay`의 날짜 계산을 단일 기준으로 사용한다.
- 마감일 당일 23:59:59까지는 진행 중이다.
- `calcDDay` 결과가 `마감됨`이면 마감 시각 상태를 적용한다.
- 마감일이 없는 상시 공지와 마감 3일 이내 공지는 기존 표현을 유지한다.

## 목록 카드

- 마감된 카드에 `card-expired` 클래스를 적용한다.
- 카드의 왼쪽 테두리는 중립 회색으로 표시한다.
- 카드 배경은 흰색과 구분되는 아주 옅은 회색을 사용한다.
- D-day 위치에는 회색 계열의 `마감` 배지를 표시한다.
- 제목과 본문에는 취소선이나 낮은 불투명도를 적용하지 않는다.
- 카드 클릭, 찜, 비교, 조회 동작은 변경하지 않는다.

## 상세 화면

- 상세 화면의 기존 정보 구조는 유지한다.
- 제목 주변의 상태 영역에 목록과 동일한 회색 `마감` 배지를 표시한다.
- 본문과 첨부파일은 흐리게 표시하지 않는다.

## 디자인 원칙

- 빨간색은 마감 임박 상태에만 사용한다.
- 마감 상태는 회색 배경·테두리·배지의 조합으로 표현한다.
- 색상만으로 상태를 전달하지 않고 `마감` 텍스트를 함께 제공한다.
- 기존 반응형 레이아웃과 키보드·마우스 상호작용을 유지한다.

## 검증

- 마감된 공지가 `card-expired` 클래스를 받는지 검증한다.
- 마감된 카드와 상세 화면에 `마감` 상태 텍스트가 표시되는지 검증한다.
- 진행 중·마감 임박·상시 공지의 기존 클래스와 배지가 바뀌지 않는지 검증한다.
- 정적 배포 산출물에 동일한 HTML, JavaScript, CSS가 복사되는지 검증한다.

## 제외 범위

- 마감 공지의 자동 숨김 또는 삭제
- 기본 정렬 순서 변경
- 제목 취소선 또는 카드 전체 투명도 감소
- 알림 발송 정책 변경
