# 좌우 레일과 빈틈없는 공지 배치 설계

## 목표

대형 데스크톱의 좌우 빈 공간을 활용해 왼쪽에는 서울대학교 메인 홈페이지에서 영감을 받은 학교 아이덴티티 레일을, 오른쪽에는 관리 가능한 세로 광고 레일을 제공한다. 중앙 공지 영역은 이미지 유무에 따라 생기는 세로 빈 공간을 다음 카드가 채우는 다단 배치로 변경한다.

## 범위

- 대형 데스크톱용 3열 페이지 셸
- 고정형 왼쪽 브랜드 레일
- 관리자 등록형 오른쪽 광고 레일
- 기존 배너 데이터의 표시 위치 구분
- 빈틈없는 공지 카드 다단 배치
- JSON 파일 저장소와 Supabase 저장소의 동등한 동작
- Cloudflare 정적 산출물과 회귀 테스트

## 페이지 셸

대형 화면에서 페이지를 다음 세 영역으로 구성한다.

```text
[왼쪽 브랜드 레일]  [기존 공지 콘텐츠]  [오른쪽 광고 레일]
```     

- 중앙 콘텐츠는 현재 최대 폭을 유지한다.
- 좌우 레일은 같은 폭과 같은 시각적 높이를 사용한다.
- 두 레일은 `position: sticky`와 상단 여백을 사용해 스크롤 중 일정 위치에 머문다.
- 중앙 콘텐츠를 덮는 고정 오버레이는 사용하지 않는다.
- 레일 두 개와 중앙 콘텐츠를 모두 표시할 수 있는 약 1880px 이상의 화면에서만 3열 셸을 활성화한다.
- 기준 폭 미만에서는 좌우 레일을 DOM에서 유지하되 CSS로 완전히 숨기고 중앙 콘텐츠만 표시한다.
- 기존 상단 배너 슬라이더는 유지한다.

## 왼쪽 브랜드 레일

- SNU Blue 계열의 짙은 파란 배경을 사용한다.
- 공식 휘장을 임의 복제하지 않는다.
- 초기 구현에는 교체 가능한 로고 이미지 영역과 임시 `SNU` 문자 마크를 사용한다.
- 로고 파일을 추가하면 이미지가 임시 문자 마크를 대체할 수 있게 한다.
- `SNU ECE 공지방` 사이트 이름을 표시한다.
- 다음 바로가기를 제공한다.
  - 서울대학교 홈페이지
  - 서울대학교 전기정보공학부
  - mySNU
  - 공지 등록
- 외부 링크에는 새 창 표시와 `noopener noreferrer`를 적용한다.
- 브랜드 레일은 광고 데이터와 관리자 배너 기능에 의존하지 않는다.

## 오른쪽 광고 레일

- 왼쪽과 외곽 크기는 대칭으로 유지한다.
- 밝은 중립 배경, 얇은 테두리, 다른 타이포그래피로 브랜드 레일과 역할을 구분한다.
- 광고 이미지 영역은 세로형 `9:16` 비율을 유지한다.
- `AD` 표시, 광고 제목, 짧은 설명, 이미지, 이동 링크를 제공한다.
- 광고 이미지에는 관리자가 입력한 대체 텍스트를 사용한다.
- 광고가 없으면 `배너 광고 문의` 안내 카드를 표시하고 문의 모달로 연결한다.
- 광고 링크는 `http:` 또는 `https:` URL만 허용한다.
- 오른쪽 레일에는 현재 활성 상태인 광고 한 건만 표시한다.
- 여러 오른쪽 광고가 저장되어 있으면 만료되지 않고 삭제되지 않은 항목 중 `order`가 가장 앞선 항목을 사용한다.

## 배너 데이터 모델

기존 `banner_slides` 저장 구조를 확장한다.

- `placement`: `header` 또는 `right_rail`
- `linkUrl` / `link_url`: 선택적인 광고 이동 URL
- `altText` / `alt_text`: 선택적인 이미지 대체 텍스트
- `description`: 선택적인 광고 설명

기존 행과 JSON 데이터는 필드가 없으면 `placement: "header"`로 해석해 현재 상단 배너 동작을 보존한다.

Supabase에는 다음 마이그레이션을 추가한다.

- `placement text not null default 'header'`
- `link_url text`
- `alt_text text`
- `description text`
- `placement` 허용값 체크 제약

공개 배너 조회 응답은 상단과 오른쪽 광고를 모두 반환하되 각 항목에 `placement`를 포함한다. 클라이언트는 위치별로 필터링해 상단 슬라이더와 오른쪽 레일을 각각 렌더링한다.

## 관리자 광고 관리

- 기존 배너 관리 영역은 “상단 배너”와 “오른쪽 세로 광고” 두 구역으로 나눈다.
- 오른쪽 광고 입력 항목:
  - 이름
  - 제목
  - 설명
  - 이미지
  - 이동 URL
  - 대체 텍스트
  - 만료일
- 서버는 위치, URL 프로토콜, 텍스트 길이와 기존 이미지 크기 제한을 검증한다.
- 생성·수정·삭제·정렬 API는 기존 인증 방식을 그대로 사용한다.
- 기존 상단 배너 생성·수정 요청에 `placement`가 없으면 `header`를 사용한다.

## 공지 카드 다단 배치

- 공지 목록은 CSS 다단 레이아웃을 사용한다.
- 각 카드는 `break-inside: avoid`와 전체 열 너비를 사용한다.
- 카드 간 세로 간격은 기존 그리드 간격과 동일하게 유지한다.
- 권장 열 수:
  - 넓은 중앙 콘텐츠: 4열
  - 중간 화면: 3열
  - 태블릿: 2열
  - 모바일: 1열
- DOM과 데이터의 최신순은 유지하지만 시각적 읽기 흐름은 위에서 아래로 진행한 뒤 다음 열로 이동한다.
- 이미지 카드 아래의 빈 공간은 다음 텍스트 카드가 채운다.
- 카드 클릭, 찜, 비교, 조회, 필터, 정렬, 마감 상태 스타일은 변경하지 않는다.
- 결과가 없을 때의 빈 상태는 열 전체 폭을 사용한다.

## 접근성과 반응형

- 색상만으로 광고와 브랜드 영역을 구분하지 않고 `AD` 텍스트를 제공한다.
- 광고 이미지에는 대체 텍스트를 사용한다.
- 키보드 포커스 스타일을 제공한다.
- 좌우 레일이 숨겨져도 중앙 콘텐츠와 모든 관리자 기능을 사용할 수 있어야 한다.
- 모바일에서는 공지 카드가 한 열로 표시되고 브랜드·광고 레일은 표시하지 않는다.
- `prefers-reduced-motion` 환경에서는 광고나 레일에 새 자동 애니메이션을 추가하지 않는다.

## 오류 처리

- 잘못된 광고 URL은 저장 요청에서 400으로 거절한다.
- 이미지가 없거나 로드에 실패하면 텍스트 광고 또는 문의 안내를 표시한다.
- 오른쪽 광고 조회 실패는 중앙 공지 렌더링을 막지 않는다.
- 기존 배너 데이터에 신규 필드가 없어도 상단 배너로 정상 표시한다.

## 검증

- 기존 배너가 `header`로 정규화되는지 테스트한다.
- 오른쪽 광고 필드가 JSON과 Supabase 응답에서 보존되는지 테스트한다.
- 잘못된 광고 URL이 거절되는지 테스트한다.
- 오른쪽 활성 광고 선택 순서를 테스트한다.
- 왼쪽 브랜드 레일과 오른쪽 광고 레일의 HTML 계약을 테스트한다.
- 대형 화면 전용 표시와 좁은 화면 숨김 CSS 계약을 테스트한다.
- 공지 목록이 다단 레이아웃과 `break-inside: avoid`를 사용하는지 테스트한다.
- 빈 상태와 모바일 한 열 동작을 테스트한다.
- `npm run prepare:public` 이후 원본과 정적 산출물이 동기화되는지 검증한다.
- 전체 서버·프론트엔드 테스트와 의존성 보안 감사를 실행한다.

## 제외 범위

- 광고 노출수·클릭수 통계
- 외부 광고 네트워크 스크립트
- 광고 입찰 또는 결제
- 모바일 사이드 광고
- 공식 서울대학교 휘장 파일의 무단 복제 또는 배포

## 참고

- 서울대학교 메인 홈페이지의 좌우 레일 구성에서 구조적 영감을 받되 동일 화면을 복제하지 않는다.
- 서울대학교 공식 휘장은 상표로 관리되므로 사용 권한이 확인된 파일로만 교체한다.
